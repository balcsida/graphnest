# ADR-0001: Use Go

- Status: Accepted
- Date: 2026-07-18

## Decision

Implement GraphNest in Go, initially requiring Go 1.26 or newer.

## Rationale

Go supplies the required HTTP, process, concurrency, structured logging, and
AST facilities without a large framework. It also matches Zoekt's ecosystem
and produces deployable binaries with no Java or JVM runtime.

## Consequences

Public models remain GraphNest-owned Go types. Reflection-heavy frameworks and
language-specific sidecars are out of scope.
