GraphNest semantic discovery

The query parser, stop-word rules, identifier segmentation and light stemming in
internal/graphquery/discovery_terms.go adapt behavior and rule data from CodeGraph
1.6.0, commit b9ca4b7981116909900368cc1686a1074cd4d4c1:
src/search/query-parser.ts, query-utils.ts, identifier-segments.ts.
Ranking constants derive from src/db/queries.ts and src/mcp/tools.ts.
The PostgreSQL projection, bounded query path and generation integration are
GraphNest implementations. CodeGraph is not a production dependency.
