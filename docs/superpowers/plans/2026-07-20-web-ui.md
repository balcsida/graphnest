# GraphNest Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a dependency-free, embedded code-search console from the existing GraphNest Go server.

**Architecture:** `internal/webui` embeds one HTML document and registers exact root routes on the existing `http.ServeMux`. Inline CSS and JavaScript keep first render to one response; the handler derives strict CSP hashes from those exact inline blocks. The client uses same-origin REST calls, keeps the bearer token in `sessionStorage`, and renders bounded results with safe DOM APIs.

**Tech Stack:** Go 1.26 `embed` and `net/http`; semantic HTML; native CSS; browser JavaScript with Fetch, `AbortController`, `sessionStorage`, and DOM APIs.

## Global Constraints

- No frontend framework, Node build, third-party JavaScript, CSS, font, icon, router, service worker, or new dependency.
- Keep `internal/webui/index.html` below 40 KiB uncompressed.
- Serve only `/` and `/index.html`; unknown paths must remain 404.
- Keep the token only in `sessionStorage` or in memory if storage is unavailable; clear it on 401.
- Never use `innerHTML`, `insertAdjacentHTML`, or another HTML string sink for API data.
- Omit `repositories` when “All authorized repositories” is selected or repository listing is unavailable/truncated.
- Preserve the raw query, abort stale searches, and render at most the server-bounded 100 matches.
- Validate outbound repository URLs as HTTPS and link to the exact match SHA/path/line with `rel="noopener noreferrer"`.
- Use strict CSP hashes for inline CSS and JavaScript; do not allow `unsafe-inline`.
- Preserve visible focus, semantic labels, live status, 44px touch targets, reduced motion, and forced-colors support.
- Create signed conventional commits; never commit directly to `main`.

- [ ] **Step 3: Implement the exact embedded handler**

Create `internal/webui/handler.go` with this shape:

```go
package webui

import (
	"crypto/sha256"
	"embed"
	"encoding/base64"
	"fmt"
	"net/http"
)

//go:embed index.html
var assets embed.FS

var document = mustReadDocument()
var contentSecurityPolicy = policyFor(document)

func Register(mux *http.ServeMux) {
	mux.Handle("GET /{$}", handler())
	mux.Handle("GET /index.html", handler())
}

func handler() http.Handler {
	return http.HandlerFunc(func(writer http.ResponseWriter, request *http.Request) {
		writer.Header().Set("Cache-Control", "no-store")
		writer.Header().Set("Content-Security-Policy", contentSecurityPolicy)
		writer.Header().Set("Content-Type", "text/html; charset=utf-8")
		writer.Header().Set("Cross-Origin-Opener-Policy", "same-origin")
		writer.Header().Set("Permissions-Policy", "camera=(), geolocation=(), microphone=(), payment=(), usb=()")
		writer.Header().Set("Referrer-Policy", "no-referrer")
		writer.Header().Set("X-Content-Type-Options", "nosniff")
		writer.Header().Set("X-Frame-Options", "DENY")
		_, _ = writer.Write(document)
	})
}
```

`mustReadDocument` must panic only for a missing embedded build asset. `policyFor` must extract the single `<style>` and single `<script>` bodies, hash their exact bytes with SHA-256, Base64-encode them, and return the following with the computed values:

```go
fmt.Sprintf("default-src 'none'; base-uri 'none'; frame-ancestors 'none'; form-action 'self'; connect-src 'self'; script-src 'sha256-%s'; style-src 'sha256-%s'", scriptHash, styleHash)
```

Use one small `inlineContent(document, "style")` helper and fail during initialization if either tag is missing or duplicated.
