# Milestone 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add GitHub Enterprise App authentication, verified webhook ingestion, a PostgreSQL durable queue, and safe default-branch indexing through the existing REST and MCP search path.

**Architecture:** `grepnest-server` owns GitHub reconciliation, webhook and user APIs, durable authorization, and search. `grepnest-indexer` claims one leased PostgreSQL job at a time, prepares a numeric-ID Git mirror/worktree, runs the pinned Zoekt indexer, verifies `/api/list`, and then publishes `indexed_sha`. Milestones 0-1 static fixture mode remains available for its existing tests, while durable mode uses PostgreSQL as the runtime source of truth.

**Tech Stack:** Go 1.26, standard-library HTTP/crypto/TLS/process APIs, `github.com/jackc/pgx/v5` v5.10.0, PostgreSQL 18.3, Git, the pinned Zoekt revision, and the existing MCP Go SDK.

## Global Constraints

- Work only on `feat/milestone-2`; never commit directly to `main`.
- Follow red-green-refactor: write one focused failing test, observe the expected failure, add the minimum implementation, and rerun the focused and affected suites.
- Create signed, single-line conventional commits of at most 72 characters; run `git status --short --branch` immediately before every commit.
- Add only `github.com/jackc/pgx/v5` v5.10.0. Do not add a GitHub SDK, ORM, migration framework, Redis, Git library, retry framework, scheduler, or testcontainers.
- GitHub App permissions are Metadata read and Contents read only. JWTs use RS256, `iat=now-60s`, `exp=now+9m`, and App ID as `iss`.
- Require HTTPS, configured hosts, redirect rejection, and system roots extended by the configured CA. Never use `InsecureSkipVerify`.
- Verify `X-Hub-Signature-256` over at most 1 MiB of untouched bytes before JSON decoding. Never persist webhook bodies.
- Principal authorization is an installation boundary plus an explicit subset of numeric GitHub repository IDs. Names are selectors/display metadata only, and an empty permitted-ID subset authorizes nothing.
- Queue constants are a two-minute lease, 30-second renewal, five attempts, and full jitter capped by `min(5s*2^(attempt-1), 5m)`.
- Index one default branch at a time. Use argument arrays, numeric-ID disk paths, a credential-free persisted remote, a fixed askpass mode, a 2 MiB file limit, `-parallelism 1`, `-disable_ctags`, and no hooks, submodules, LFS smudge, repository execution, or file protocol.
- Search and file reads fail closed unless repository and installation are enabled and Zoekt's branch/version equals committed `indexed_sha`.
- Do not begin image hardening, Helm, OpenShift, multi-node routing, outlines, admin reindex, physical shard deletion, or other Milestone 3 work.
