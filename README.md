# GrepNest

GrepNest is a pre-pilot code-search service. Only Milestones 0-1 exist today.

The module path, `github.com/grepnest/grepnest`, is temporary because this
repository has no remote yet. Zoekt is an internal implementation detail and
must not be exposed directly to clients.

## Development

Run `make fmt lint test test-race build` before proposing a change.
